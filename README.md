# Sales Prediction Using Python

## Project Overview
This project predicts sales based on advertising expenditure using TV, Radio and Newspaper advertising data.

## Objective
To build a machine learning model that predicts sales and analyzes the impact of different advertising investments.

## Dataset
The dataset contains 200 records with the following variables:
- TV
- Radio
- Newspaper
- Sales

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Machine Learning Model
Linear Regression

## Model Performance
- MAE: 1.46
- RMSE: 1.78
- R² Score: 0.8994

## Results
The model predicts sales based on TV, Radio and Newspaper advertising expenditure. Different advertising scenarios were also tested to compare predicted sales.

## Limitation
The dataset does not contain Target Segment, Platform or Date/Time information. Therefore, these factors were not included in the analysis.
